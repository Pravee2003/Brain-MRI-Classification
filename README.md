# Brain Tumor Classification using Hybrid Deep Learning Model

## Overview
This project presents a hybrid framework for brain tumor classification using deep learning and machine learning techniques.

## Technologies Used
- PyTorch (Feature Extraction)
- XGBoost (Classification)
- Scikit-learn (Evaluation)
- Optuna (Hyperparameter Optimization)

## Dataset
Dataset used: https://sageb.io/RaTSO5

## Methodology
1. Image preprocessing
2. Feature extraction using deep learning models
3. Classification using XGBoost
4. Hyperparameter tuning using TPE (Optuna)

## Results
The model achieves high accuracy and stability across validation datasets.

## How to Run
1. Install dependencies: pip install -r requirements.txt
2. Run the main script
